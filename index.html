제가 일하는 방식

01
내가 겪은 진짜 불편에서 시작한다. 남의 아이디어가 아니라, 매달 반복하던 내 업무의 페인포인트를 문제로 정의했습니다.

기획서가 아니라 동작하는 것으로 증명한다. 대화형 AI로 코드를 짜서, 실제 배포 가능한 상태까지 만들었습니다.
03
사용자와 리스크를 먼저 생각한다. 얼굴 사진 차단·개인정보 제거·데이터 등급 분리 — 만들기 전에 지킬 선부터 그었습니다.

만든 서비스

01
💰

단가 에이전트

서비스 기획 · 데이터 설계 · 구현 · 배포 — 전 과정 단독
실무 도입Live
◦ Problem

40개 넘는 캠페인 시트에 인플루언서 단가가 제각각 흩어져, 매달 "이 채널 얼마였지?"를 손으로 찾아야 했습니다.

◆ Solution

채널 링크를 유일 키로 삼아 흩어진 단가를 통합하고, 예산·유형별로 1초 만에 조회하는 웹 도구를 만들었습니다.

  • 통합 검색 · 예산 필터 · 엑셀 붙여넣기 자동 매칭 — 이름이 비슷하면 링크로 식별
  • "고객사 공유가 / 내부 실비" 데이터 등급을 분리해 실비 노출 사고를 원천 차단
  • AI가 지적한 연락처 유출 리스크를 받아들여, 실데이터는 구글 로그인·시트 공유자만 접근하도록 재설계
Google Sheets · Apps Script · Web 데모 열기 (가상 데이터) ↗
02
🎯

GoalFlow

MVP 기획 · AI 흐름 설계 · 풀스택 구현 · 배포
Live
◦ Problem

사람들은 대화 속에서 "하고 싶은 것"을 흘리지만, 그게 목표와 실행으로 이어지지 않고 흩어집니다.

◆ Solution

대화에서 잠재 목표를 감지·제안하고, 승인하면 단계별 로드맵과 할 일로 자동 전개되는 웹앱.

  • 대화형 구체화(추가 질문) → 사용자가 승인해야만 저장 — AI가 마음대로 결정하지 않는 경계
  • 이메일·초대코드 자체 인증으로 사용자 데이터 격리, 관리자 권한은 서버에서 검증
  • 초기 외부 도구(Atoms)의 한계를 파악하고 자체 인증 + Gemini로 직접 전환
FastAPI · React · Postgres · Gemini 라이브 앱 열기 ↗
03
🌸

꽃맵

컨셉 기획 · 프라이버시 설계 · 구현
Prototype
◦ Problem

"지금 어디에 꽃이 피었나"는 검색으로 안 나옵니다. 시즌·위치 정보는 사람들 머릿속에만 있어요.

◆ Solution

'가슴속 삼천원'처럼 사용자 제보로만 채워지는 시즌 꽃 지도. 능소화 시즌엔 능소화 핀 곳을 서로 알려줍니다.

  • 얼굴 자동 차단(face-api) · 사진 EXIF·GPS 제거 · 핀 좌표 뭉개기(~11m) — 특정 주택 지목 방지
  • 익명 읽기+제보만 허용, 남의 글 수정·삭제 불가(RLS) · 신고 시 자동 숨김
  • 전국 30여 종 꽃 명소를 미리 시드로 채워 빈 지도(cold start) 문제를 완화
Next.js · Supabase · 네이버 지도 API
04
🏢

연결오피스

기획 · 화면 흐름 설계 · 구현
Prototype
◦ Problem

원격·유연근무에서 "지금 누가 일하고 있는지", "이번 주 뭘 하는지"가 서로 안 보입니다.

◆ Solution

출퇴근·실시간 상태·주간 업무·집중 타이머를 한 화면에 모은 가벼운 가상 오피스.

  • 출근/퇴근 · 실시간 팀 상태 · 주간 업무 보드 · 집중 타이머 — 일상 협업 루틴을 한 곳에
  • 로그인·프로필·피드·리포트까지 실제 화면 흐름 단위로 설계
React · TypeScript · Tailwind · Supabase
