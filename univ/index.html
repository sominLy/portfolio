PROJECT 03 · 시장에 가면

외국인의 탐색 행동을 유스케이스와 화면으로 정리했습니다.

글로벌 커뮤니티 데이터를 분석해 음식명을 모르면 사진을 먼저 보고 판매처를 찾는다는 점을 확인했습니다. GPS 정확도에 기대던 초기안을 버리고 이미지 탐색과 NFC 정보 등록 방식으로 방향을 바꿨습니다.

나의 역할컨셉 기획과 데이터 분석을 주도하고, 확인한 행동을 기능 명세와 화면 흐름에 반영했습니다.
협업 방식유스케이스 18종과 화면 설계에 판단 근거를 함께 적어 기획·디자인·개발팀이 같은 내용을 확인하게 했습니다.
대학 사업과의 연결교육·연구 현장의 요구도 조사한 뒤 사용 시나리오와 제안 자료로 정리할 수 있습니다.
