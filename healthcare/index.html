인사이트

음식명을 모르면 이미지를 먼저 보고 판매처를 찾으며, 점포 운영자는 정보를 계속 관리하기 어렵습니다.

Problem → Decision → Result

초기 접근

사용자가 올린 음식 사진의 GPS 좌표를 점포와 연결하면 정보를 빠르게 갱신할 수 있다고 봤습니다.

확인한 한계

시장 내부에서는 위치 오차가 커 특정 점포를 안정적으로 구분하기 어려웠습니다. 정확하지 않은 위치는 서비스 신뢰를 떨어뜨릴 수 있었습니다.

방향을 바꾼 근거

외국인은 음식명을 모를 때 사진을 먼저 보고 판매처를 찾았습니다. 따라서 정밀 위치보다 이미지에서 탐색을 시작하는 흐름이 실제 행동에 가까웠습니다.

실행안

이미지 중심 탐색과 점포별 NFC 정보 등록을 연결하고, 팀이 구현할 수 있도록 유스케이스와 기능 명세로 옮겼습니다.

검증된 결과

데이터 분석과 기능 설계의 연결성을 인정받아 LG DX School 장려상을 수상했습니다.

질문 설계 기준

사내에서 실제 검토하는 이슈와 참여자 관심사가 겹치는 지점을 먼저 찾고, 비교와 이유가 드러나는 질문으로 구체화했습니다.

PROJECT 04 · 꽃맵

서비스 맥락

사용자가 꽃 사진과 발견 위치를 공유하면 주변의 개화 정보를 함께 만드는 지도 서비스입니다.

숨은 위험

사진에는 타인의 얼굴이, 파일에는 정확한 촬영 위치가 남을 수 있어 공개 데이터가 개인 정보 노출로 이어질 수 있었습니다.

문제 정의

정보의 정확도를 최대화하는 것보다, 서비스에 꼭 필요한 수준만 남기는 수집·공개 원칙이 먼저 필요했습니다.

사진을 받는 순간타인의 얼굴을 자동으로 가려 사진 공유 과정의 노출 위험을 줄입니다.
파일을 저장하기 전에기기에 남은 촬영 정보와 EXIF 메타데이터를 제거합니다.
지도에 공개할 때정확한 좌표 대신 주변 범위로 표시해 꽃 정보의 활용성과 위치 보호를 함께 확보합니다.
배운 점특히 민감한 데이터를 다루는 AI 사업은 활용 가치와 사용자 신뢰를 같은 설계 안에서 다뤄야 합니다.
